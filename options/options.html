🐾悬浮球形象

挑一个预设角色，或上传自定义图片（支持 GIF 动图）；选择后立即生效，无需点保存。

图片仅保存在本机 chrome.storage.local（不超过 1MB），不会上传到任何服务器；GIF 会保留动画，悬浮球的呼吸浮动效果不变。

⭐收藏本（最近 50 条收藏）

在结果卡片点击「收藏」即可把摘要/解释存入收藏本。

📖术语本

摘要与解释会按术语本理解相关词汇；在解释卡片点击「存术语」也可一键加入。

📦配置导入 / 导出

导出内容：LLM API 配置、摘要风格、输出语言、阅读提醒、术语本、收藏本与悬浮球形象；导入会覆盖当前全部设置，导入后所有打开页面即时生效。

快捷键可在 edge://extensions/shortcuts 中修改（默认 Alt+S 摘要本页、Alt+E 解释选中内容）。
