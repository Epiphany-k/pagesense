# PageSense 网页摘要与解释

一款面向 Edge 浏览器（兼容 Chrome）的轻量级 AI 阅读助手：悬浮球一键摘要整页或划词内容、解释难句与术语，结果以页面内小卡片流式展示。自带任意 OpenAI 兼容 API，密钥只存本地。

## 功能特性

**摘要与解释**
- 智能分流：有选区时摘要选中段落，无选区时摘要整页
- 划词解释：术语、难句、代码、外语一段话讲清
- 摘要风格：一句话 / 一句话+要点 / 短段落 / 自定义（自然语言描述你想要的样式）
- 输出语言：中文 / English / 跟随原文
- 长文 Map-Reduce：分段摘要自动合并，3 路并发提速

**文献阅读优化**
- 正文降噪：剔除公式乱码（MathML / KaTeX / MathJax / latexml）、参考文献列表，保留图表标题
- 术语本：维护术语解释偏好，自动注入提示词，越用越懂你的语境；解释卡片可一键存术语
- 收藏本：摘要/解释一键收藏（最近 50 条），关键字搜索，批量导出 Markdown

**交互**
- 常驻悬浮球：点击摘要、悬停展开菜单、拖动并跨会话记忆位置，鼠标与触屏均可操作
- 流式结果卡片：边生成边显示，支持复制 / 导出 MD / 停止 / 重新生成
- 右键菜单 + 快捷键（Alt+S 摘要本页、Alt+E 解释选中内容）
- 阅读提醒：连续阅读设定时长后气泡提醒休息

**稳定性**
- 任务按标签页隔离，新任务自动取消同页旧任务
- 90 秒停滞超时自动中断，流式输出中可随时停止，半截结果可导出

## 安装

1. 下载本仓库（Code → Download ZIP 并解压）
2. 打开 Edge，进入 `edge://extensions`
3. 开启「开发人员模式」
4. 点击「加载解压缩的扩展」，选择解压后的 `pagesense` 目录

## 配置

首次使用需在设置页填写任意 OpenAI 兼容的 API：

| 配置项 | 说明 |
| --- | --- |
| Base URL | 如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`（自动补全 `/chat/completions`） |
| API Key | 仅保存在本机 `chrome.storage.local`，不上传任何第三方 |
| 模型名称 | 如 `deepseek-chat` / `gpt-4o-mini` / `glm-4-flash` |

打开方式：悬浮球菜单 →「设置」，或结果卡片 →「设置」。填写后可点击「测试连接」验证。

## 目录结构

```
pagesense/
├── manifest.json        # MV3 清单
├── background/          # Service Worker：消息路由、LLM 调用（SSE 流式）、长文 Map-Reduce
├── content/              # 内容脚本：正文提取、悬浮球、结果卡片（Shadow DOM 隔离）
├── options/              # 设置页：API 配置、风格与语言、收藏本、术语本
├── popup/                # 工具栏弹窗
└── shared/               # 共享常量与 Markdown 渲染
```

## 隐私

- API 密钥与所有数据（收藏、术语、配置）仅存储于浏览器本地
- 所有 LLM 请求由你的浏览器直接发往你配置的 API 地址，不经过任何中间服务器
- 无任何统计上报
