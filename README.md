# ✦ PageSense — 你的网页摘要与解释助手

一个轻量、无打扰的 AI 阅读伴侣：**悬浮球一键摘要整页或划词内容，划词秒懂术语与难句**，结果以页面内小卡片流式展示。自带任意 OpenAI 兼容 API，密钥只存本地，特别为**文献阅读**优化。

## ✨ 功能一览

### 🔮 页面右下角的悬浮球

- **点击即摘要**：有选中文字时摘要选中段落，无选区时摘要整页，自动智能分流
- **悬停展开菜单**：摘要本页 / 解释选中内容 / 摘要选中内容 / 设置
- **自由拖动**：拖到顺手的位置，刷新和新开标签页都会记住
- **鼠标与触屏通用**：触屏长按展开菜单，拖动不干扰页面滚动
- 可在设置中随时关闭悬浮球

### 🪟 结果小卡片

- **流式输出**：答案边生成边显示，无需等待
- **复制**：一键复制结果
- **导出 MD**：下载 Markdown 文件，包含摘要结果与原文，原文自动剔除站点噪音
- **停止 / 重新生成**：生成中可随时停止，结束后可重新生成
- **收藏**：一键存入收藏本
- **存术语**：解释结果一键存入术语本
- 卡片可拖动到屏幕任意位置

### 🖱️ 三种触发方式

| 方式 | 操作 |
| --- | --- |
| 悬浮球 | 点击摘要，悬停开菜单 |
| 右键菜单 | 「PageSense：摘要此页面 / 解释选中内容 / 摘要选中内容」 |
| 快捷键 | `Alt+S` 摘要当前页，`Alt+E` 解释选中内容（可在 `edge://extensions/shortcuts` 自定义） |

### ⚙️ 设置页

- **LLM API**：Base URL / API Key / 模型名称 / 温度，一键测试连接
- **摘要风格**：一句话 / 一句话+要点 / 短段落 / **自定义**（用自然语言描述你想要的摘要样式）
- **输出语言**：中文 / English / 跟随原文
- **收藏本**：最近 50 条收藏，关键字搜索（标题+内容），单条删除、清空、导出全部为一份 Markdown 文档
- **术语本**：添加/删除术语，摘要与解释自动按你的解释理解相关词汇
- **阅读提醒**：连续阅读达到设定时长后，悬浮球气泡提醒休息

### 📚 文献阅读优化

- **正文降噪**：自动剔除公式乱码与参考文献列表，保留图表标题，摘要质量更高
- **长文提速**：超长正文分段摘要后合并，并发请求，长文献等待时间大幅缩短
- **术语积累**：术语本越用越懂你的语境，读得越多解释越准

## 📦 安装

无需构建，下载即用：

1. 点击右上角 **Code → Download ZIP** 并解压
2. 打开 Edge，进入 `edge://extensions`（Chrome 用户进入 `chrome://extensions`）
3. 开启 **开发人员模式**
4. 点击 **加载解压缩的扩展**，选择解压出的 `pagesense` 目录

## 🔧 配置 API

首次使用需填写任意 OpenAI 兼容 API（设置页入口：悬浮球菜单 → ⚙️ 设置）：

| 配置项 | 说明 |
| --- | --- |
| Base URL | 如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`（自动补全 `/chat/completions`） |
| API Key | 如 `sk-...`，仅保存在本机 |
| 模型名称 | 如 `deepseek-chat` / `gpt-4o-mini` / `glm-4-flash` |

填写后点 **测试连接**，提示"连接成功"即可开始使用。

## 🛡️ 权限与隐私

- `activeTab` / `scripting`：提取当前页面正文、注入悬浮球与结果卡片
- `storage`：本地保存配置、收藏本、术语本与悬浮球位置
- `contextMenus`：右键菜单
- **隐私**：API 密钥与全部数据仅存于浏览器本地；LLM 请求由浏览器直接发往你配置的 API 地址，不经过任何中间服务器；无统计上报

## 📂 目录结构

```
pagesense/
├── manifest.json        # MV3 清单
├── background/          # Service Worker：消息路由、LLM 调用（SSE 流式）、长文编排
├── content/              # 内容脚本：正文提取、悬浮球、结果卡片（Shadow DOM 样式隔离）
├── options/              # 设置页：API 配置、风格语言、收藏本、术语本
├── popup/                # 工具栏弹窗
└── shared/               # 共享常量与 Markdown 渲染
```
