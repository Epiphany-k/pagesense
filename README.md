# ✦ PageSense — 你的网页摘要与解释助手

一个轻量、无打扰的 AI 阅读伴侣：**悬浮球一键摘要整页或划词内容，划词秒懂术语与难句**，结果以页面内小卡片流式展示。自带任意 OpenAI 兼容 API，密钥只存本地。特别为**文献阅读**做了优化——正文降噪、术语积累、长文并发提速。

## 💡 定位

**PageSense = Page + Sense**：让浏览器"读懂"网页。

- 不做侧边栏、不做追问、不做花哨面板——**一个悬浮球 + 一张小卡片**就是全部界面
- 摘要简短直接、解释通俗易懂，看完即走，不浪费阅读时间
- 主要面向**读文献**的场景：论文、技术文档、英文资料

## ✨ 特性亮点

- 🔮 **常驻悬浮球**：点击摘要（有选区摘要选中段落，无选区摘要整页）、悬停展开菜单、拖动并跨会话记忆位置，鼠标与触屏都能用
- ✂️ **划词解释**：术语、难句、代码、外语，一两句话讲清；选区被站点脚本清除时自动用快照兜底
- 🎨 **摘要风格**：一句话 / 一句话+要点 / 短段落 / **自定义**（用自然语言描述你想要的样式）
- 🌐 **输出语言**：中文 / English / 跟随原文
- 📚 **文献降噪**：自动剔除公式乱码（MathML / KaTeX / MathJax / latexml）、参考文献列表，保留图表标题
- ⚡ **长文提速**：超长正文 Map-Reduce 分段摘要，3 路并发请求，长文献等待时间降为约 1/3
- ⭐ **收藏本**：摘要/解释一键收藏（最近 50 条），关键字搜索，批量导出 Markdown
- 📖 **术语本**：维护术语解释偏好自动注入提示词，越用越懂你的语境；解释卡片可一键存术语
- 🖱️ **多入口**：右键菜单、快捷键、悬浮球菜单三选一
- ⏰ **阅读提醒**：连续阅读达到设定时长后气泡提醒休息
- 🛑 **可控任务**：流式输出中随时停止，90 秒无响应自动中断，半截结果也能导出

## 📦 安装

无需构建，下载即用：

1. 点击右上角 **Code → Download ZIP** 并解压
2. 打开 Edge，进入 `edge://extensions`（Chrome 用户进入 `chrome://extensions`）
3. 开启右上角 **开发人员模式**
4. 点击 **加载解压缩的扩展**，选择解压出的 `pagesense` 目录
5. 建议把 PageSense **固定**到工具栏，方便打开弹窗

## 🔧 使用说明

### 首次配置

打开设置页（工具栏图标 → 设置，或悬浮球菜单 → ⚙️ 设置），填写任意 **OpenAI 兼容 API**：

| 配置项 | 说明 |
| --- | --- |
| Base URL | 如 `https://api.deepseek.com` 或 `https://api.openai.com/v1`（自动补全 `/chat/completions`） |
| API Key | 如 `sk-...`，仅保存在本机，不上传任何第三方 |
| 模型名称 | 如 `deepseek-chat` / `gpt-4o-mini` / `glm-4-flash` |

填好后点 **测试连接** 验证，提示"连接成功"即可开始使用。

### 日常使用

- **整页摘要**：直接点击页面右下角的悬浮球（无选区时自动走整页）
- **划词摘要**：选中一段文字 → 点击悬浮球；或右键 → 「PageSense：摘要选中内容」
- **划词解释**：选中术语/难句 → 右键 → 「PageSense：解释选中内容」；或悬浮球菜单 → 💡 解释选中内容
- **触屏用户**：长按悬浮球展开菜单，拖动时不会触发页面滚动

### 结果卡片

结果以悬浮小卡片流式展示（可拖动到任意位置）：

- **复制**：结果一键复制
- **导出 MD**：生成包含结果与原文的 Markdown 文件，原文自动剔除站点噪音（导航、版权、互动按钮等）
- **停止 / 重新生成**：流式输出中按钮变「停止」，随时中断；结束后点「重新生成」重跑
- **收藏**：存入收藏本，之后可在设置页回看
- **存术语**（仅解释任务）：把选中文本 + 解释存入术语本，后续摘要/解释自动按此理解

### 设置页管理

- **输出偏好**：摘要风格（含自定义）、输出语言、阅读提醒时长、悬浮球开关
- **收藏本**：关键字搜索（标题+内容）、单条删除、清空、导出全部为一个综述式 Markdown
- **术语本**：添加/删除术语，同名覆盖更新；解释卡片一键存入也在这里

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt+S` | 摘要当前页面 |
| `Alt+E` | 解释选中内容 |

可在 `edge://extensions/shortcuts` 中自定义。

## 📚 文献阅读优化

- **正文降噪**：提取正文时剔除公式渲染容器的乱码符号流；识别到 References / 参考文献 / 致谢 等标题后截断引用列表（通常占正文 20-40% 的 token）；保留 `Figure 1: …` 图表标题让摘要覆盖实验结论
- **分段并发**：正文超过约 1.8 万字自动走 Map-Reduce：分段摘要 → 合并整体摘要，分段请求 3 路并发
- **术语注入**：术语本非空时，摘要与解释的提示词自动附加术语表（最多 20 条），保证专有名词按你的语境理解

## 🛡️ 权限与安全

- `activeTab` / `scripting`：提取当前页面正文、动态注入内容脚本
- `storage`：本地保存配置、收藏本、术语本与悬浮球位置
- `contextMenus`：右键菜单
- `host_permissions: <all_urls>`：向任意网页注入悬浮球与结果卡片
- **隐私**：API 密钥与全部数据仅存于浏览器本地；LLM 请求由浏览器直接发往你配置的 API 地址，不经过任何中间服务器；无统计上报

## 📂 目录结构

```
pagesense/
├── manifest.json        # MV3 清单
├── background/          # Service Worker：消息路由、LLM 调用（SSE 流式）、Map-Reduce 编排
├── content/              # 内容脚本：正文提取、悬浮球、结果卡片（Shadow DOM 样式隔离）
├── options/              # 设置页：API 配置、风格语言、收藏本、术语本
├── popup/                # 工具栏弹窗
└── shared/               # 共享常量与 Markdown 渲染
```

## 🔬 调试与常见问题

- **摘要提示"正文较短"**：页面内容为动态加载（SPA）时，等待内容加载完成后再摘要
- **PDF 页面不工作**：浏览器内置 PDF 查看器是内部页面，无法注入内容脚本，请使用网页版文献
- **点菜单时选区丢失**：已内置选区快照兜底（500ms 宽限），若仍失败请确认选区未取消超过半秒
- **插件重载后旧页面悬浮球失效**：刷新该页面即可；旧实例会自动清理
- **API 报错**：401/403 密钥无效、404 地址或模型名错误、429 请求过频——按卡片提示到设置页检查
- **请求卡住不动**：90 秒无数据会自动中断，可直接点「停止」
